## 6. Code Quality Notes

### 6.1 N+1 Query Issue

`ArticleService.get_articles()` (article_service.py:97-135)에서 각 조문별로 3개의 추가 쿼리를 실행 (ordinance_count, change_count, last_change). 20건 조회 시 60개 추가 쿼리 발생.

**설계 문서 Section 9.2**에서 이 문제를 인지하고 Subquery 최적화를 제안했으나 미적용.

### 6.2 Incomplete Paragraph Parsing

`MolegClient._parse_paragraphs()` (moleg_client.py:148-151)이 TODO 상태로 빈 리스트를 반환. 설계 문서 Section 6.1의 `parse_paragraphs` 알고리즘이 구현되지 않음.
