### 제2절 문장 정비의 실제
- p.121

#### 1. 바른 문장 쓰기 — p.121
- 가. 주어를 분명히 밝힌다 — p.122
  - 1) 법령 문장에는 원칙적으로 주어를 쓴다 — p.122
  - 2) 주어가 잘 드러나도록 쓴다 — p.126
  - 3) 주격 조사와 보조사를 적절하게 사용한다 — p.128
- 나. 목적어를 분명히 밝힌다 — p.130
  - 1) 생략된 목적어를 찾아 쓴다 — p.130
  - 2) 목적어의 형태를 갖춘다 — p.131
  - 3) 목적어를 서술어 앞에 둔다 — p.131
  - 4) 목적어를 서술어와 잘 어울리도록 쓴다 — p.132
- 다. 주어와 서술어의 관계를 명확히 한다 — p.133

#### 2. 간결한 문장 쓰기 — p.135
- 가. 긴 문장은 짧게 나누어 쓴다 — p.135
  - 1) 항으로 나누어 규정하는 경우 — p.135
  - 2) 단서를 두는 경우 — p.142
  - 3) 후단을 두는 경우 — p.144
  - 4) 열거된 사항을 호나 목으로 나누어 규정한 정비사례 — p.145
- 나. 중복되거나 불필요한 내용은 삭제한다 — p.148

#### 3. 명확한 문장 쓰기 — p.152
- 가. '또는', '및'의 접속 관계를 분명하게 쓴다 — p.152
- 나. 의미가 불명확한 수식어를 쓰지 않는다 — p.156
- 다. 중의적, 다의적 표현은 정확한 표현으로 고쳐 쓴다 — p.157
- 라. 이중 부정문은 되도록 긍정문으로 쓴다 — p.157
- 마. 지시어의 내용을 직접 쓴다 — p.159
- 바. 문맥상 필요한 내용을 생략하지 않는다 — p.162

#### 4. 자연스러운 문장 쓰기 — p.166
- 가. 되도록 능동문으로 쓴다 — p.166
- 나. 일본어 투 표현을 쓰지 않는다 — p.169

  - 2) 일본어 투 표현의 정비 — p.170
