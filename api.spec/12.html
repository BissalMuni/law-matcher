OPEN API 활용가이드

자치법규 본문 조회 API

- 요청 URL : http://www.law.go.kr/DRF/lawService.do?target=ordin
요청 변수 (request parameter)
요청변수 안내
요청변수 값 설명
OC string(필수) 사용자 이메일의 ID(g4c@korea.kr일경우 OC값=g4c)
type char(필수) 출력 형태 HTML/XML/JSON
target string : ordin(필수) 서비스 대상
ID char 자치법규ID
MST string 자치법규 일련번호
샘플 URL
1. 자치법규 MST HTML 조회
http://www.law.go.kr/DRF/lawService.do?OC=test&target=ordin&MST=1316146&type=HTML&mobileYn=
2. 자치법규 ID XML 조회
http://www.law.go.kr/DRF/lawService.do?OC=test&target=ordin&ID=2026666&type=XML&mobileYn=
3. 자치법규 ID JSON 조회
http://www.law.go.kr/DRF/lawService.do?OC=test&target=ordin&ID=2251458&type=JSON&mobileYn=
출력 결과 필드(response field)
출력 결과 필드 안내
필드 값 설명
자치법규ID int 자치법규ID
자치법규일련번호 string 자치법규일련번호
공포일자 string 공포일자
공포번호 string 공포번호
자치법규명 string 자치법규명
시행일자 string 시행일자
자치법규종류 string 자치법규종류
(C0001-조례 /C0002-규칙 /C0003-훈령
/C0004-예규/C0006-기타/C0010-고시
/C0011-의회규칙)
지자체기관명 string 지자체기관명
자치법규발의종류 string 자치법규발의종류
담당부서명 string 담당부서명
전화번호 string 전화번호
제개정정보 string 제개정정보
조문번호 string 조문번호

그 외 편,장,절,관 일때는 N

부칙공포일자 int 부칙공포일자

부칙내용 string 부칙내용

별표 string 별표

별표번호 int 별표번호
